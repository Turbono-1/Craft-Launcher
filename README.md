# 🎮 Craft Launcher

> A lightweight, simple and user-friendly Minecraft launcher for Android, built with performance, customization and ease of use in mind.

![Craft Launcher](https://img.shields.io/badge/Craft%20Launcher-Minecraft-green)
![Platform](https://img.shields.io/badge/Platform-Android-brightgreen)
![Status](https://img.shields.io/badge/Status-In%20Development-orange)
![License](https://img.shields.io/badge/License-MIT-purple)

## ✨ Features

* 🚀 **Lightweight** — Designed to keep resource usage low.
* 🎮 **Minecraft Support** — Launch and manage Minecraft easily.
* 📦 **Mod Support** — Manage your Minecraft mods.
* 🔧 **Custom Configuration** — Configure launcher and game settings.
* 🌐 **Simple UI** — Clean and easy-to-use interface.
* ⚡ **Performance Focused** — Designed with low-end Android devices in mind.
* 🧩 **Customizable** — More customization features coming soon.

## 📱 Platform

Craft Launcher is currently designed for:

**Android 📱**

## 📋 System Requirements

### Minimum

| Requirement     | Specification |
| --------------- | ------------- |
| 📱 Platform     | Android       |
| 🧠 RAM          | 2 GB          |
| ⚙️ CPU          | 500 MHz       |
| 💾 Free Storage | 5 GB          |

### Recommended

| Requirement     | Specification |
| --------------- | ------------- |
| 📱 Platform     | Android       |
| 🧠 RAM          | 4 GB          |
| ⚙️ CPU          | 1.10 GHz      |
| 💾 Free Storage | 5–10 GB       |

> 💡 More free storage may be required depending on the Minecraft version, mods and additional game files.

## 📥 Installation

1. Go to the **Releases** section of this repository.
2. Download the latest Craft Launcher APK.
3. Install the APK on your Android device.
4. Open Craft Launcher.
5. Configure your Minecraft installation.
6. Launch the game and enjoy! 🎮

## 🛠️ Development

Clone the repository:
